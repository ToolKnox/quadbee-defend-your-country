# QuadBee - Defend Your Country!

QuadBee is an open-source 7" 6S ExpressLRS FPV quad built around a Mark 4 style frame, SpeedyBee F405 V3 stack, and EMAX ECO II 2807 motors.

The 3D-printing platform listings are kept focused on printable/CAD files. This GitHub repository is the source of truth for the build resources, BOM, and instructions.

## Printing notes

Use strong, heat-resistant material for flight parts. Good starting choices are PC-CF, PA-CF, ASA, ABS, PCTG, or PETG. TPU is useful for antenna brackets and vibration-isolating parts.

Suggested starting settings:

- 0.2 mm layer height
- 4 walls
- 5 solid top/bottom layers
- 35% infill
- Gyroid, honeycomb, triangle, or cubic infill
